# CompStak

> CompStak is a commercial real estate (CRE) data platform that crowdsources and verifies lease comps, sale comps, loan data, and property data from a network of brokers and appraisers, and exposes that data to enterprise customers through the CompStak platform and a contact-sales Data API.

CompStak's public developer surface is enterprise/contact-sales only — there is no self-serve developer portal, public OpenAPI specification, SDK, or API reference. The Data API is offered as an integration product (Market Insights, Property Insights, Space Insights, and Property Standardization) and is provisioned through sales. This llms.txt is generated by the API Evangelist enrichment pipeline from the public website; it is not a provider-published document.

## Products
- [CompStak One](https://compstak.com): All-in-one CRE data platform with lease comps, sale comps, loan data, and property data
- [CompStak Data API](https://compstak.com/data-api): Enterprise CRE data integration — Market Insights, Property Insights, Space Insights, Property Standardization
- [CompStak Exchange](https://compstak.com): Data exchange platform for brokerages and appraisal firms
- [CompStak AI](https://compstak.com): AI capabilities paired with verified CRE data
